# Indian Startup Funding Analysis (2015–2017)

## 📌 Project Overview
This project analyzes funding trends in Indian startups using data from 2015 to 2017.  
The goal is to identify key funding patterns, top cities, major investors, and hot industry sectors.

---

## 🎯 Objectives
- Analyze year-wise funding trends
- Identify top cities receiving funding
- Find most active investors
- Discover top funded industries
- Visualize funding distribution

---

## 🛠️ Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset Features
- Date
- Startup Name
- Industry Vertical
- City Location
- Investors Name
- Investment Type
- Amount in USD

---

## 🔧 Data Cleaning Steps
- Converted Date column to datetime
- Removed invalid dates
- Cleaned funding amounts (removed commas, converted to numeric)
- Standardized city names (Delhi → New Delhi, bangalore → Bangalore)
- Extracted primary investor name

---

## 📊 Key Insights
- Funding activity increased significantly after 2015
- Bangalore is the top funding hub
- E-commerce and FinTech sectors dominate
- A small number of investors account for most investments
- Funding is concentrated in metro cities

---

## 📈 Visualizations
- Funding trend over years (line chart)
- Top 10 cities by funding (bar chart)
- Top investors (bar chart)
- Top funded industries (bar chart)
- Funding distribution (histogram)
- City vs Industry heatmap

---

## 🚀 How to Run
1. Clone the repository
2. Place `startup_funding.csv` inside the project folder
3. Open `analysis.ipynb`
4. Run all cells
